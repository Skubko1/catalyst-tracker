# Измерительный слой

`run-study.mjs` считает **event-study**: абнормал-ретёрн (доходность монеты минус
доходность BTC) в окнах 7/30/90 дней вокруг каждого катализатора, сгруппированный
по типу и априору направления.

## Что нужно заполнить
Таблицу `prices (coin_ref, day, close)` — включая BTC (`coingecko:bitcoin`).
`day` — unix-секунды полуночи UTC. Тянешь историю из CoinGecko
(`/coins/{id}/market_chart/range`) отдельным скриптом; `coin_ref` должен
совпадать с тем, что пишут детекторы (`coingecko:<id>`).

## Дисциплина (иначе цифры соврут)
- **Look-ahead**: study пропускает события, чьё `event_ts + H` ещё не в прошлом.
- **Де-бетинг**: считаем абнормал, а не сырую доходность — иначе измеришь рынок,
  а не катализатор. По-хорошему добавь ещё секторный индекс.
- **Покрытие**: репортится `n=covered/seen`. Низкое покрытие → выводам не верить.
- **Мультитест**: типов много; при n<~20 в бакете это шум, не сигнал.
- **survivorship**: цены нужны и по ныне мёртвым монетам, что были в топе тогда,
  иначе выборка перекошена в выживших.

## Апгрейд
Когда наберётся объём — заменить «минус BTC» на регрессию (α/β к рынку и сектору),
добавить доверительные интервалы и walk-forward по времени.
